# Proyecto Intermodular ASIR

## Sistema de gestión y servicios para un Club de Pádel con cafetería

Proyecto Intermodular del ciclo de Administración de Sistemas Informáticos en Red (ASIR).

El proyecto plantea el diseño de un sistema de gestión para un Club de Pádel en Talavera de la Reina, orientado a la gestión de reservas, actividades deportivas, torneos, clientes, socios y servicios del club.

La documentación técnica del proyecto se publica mediante MkDocs y GitHub Pages.
